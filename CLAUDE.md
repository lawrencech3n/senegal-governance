# Project

ECON 30 capstone: comparative governance and political stability in Senegal vs. neighboring Francophone states. Built with Next.js 14 (App Router) + TypeScript + Tailwind + Recharts.

# Commands

- `pnpm dev` — dev server on :3000
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm build` — production build
