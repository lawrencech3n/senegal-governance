# Project

Lawrence's econ project: an interactive site about French exploitation of Senegal, before and after independence (1960). Built with Next.js 14 (App Router) + TypeScript + Tailwind + Recharts + react-leaflet.

# Commands

- `pnpm dev` — dev server on :3000
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm build` — production build
